# Cutroom Studio

A local video clipping application that turns YouTube videos and Twitch clips into vertical videos for TikTok and YouTube Shorts.

## Features
- Speech transcription and captions
- Transcript-based highlight suggestions
- Full-video splitting by clip count or duration
- 1080 × 1920 vertical video exports
- Individual MP4 and batch ZIP downloads
- Processing progress and render caching

## Technologies
JavaScript, HTML, CSS, Node.js, Python, and FFmpeg.

## Project status
Runs locally with a Node.js server and Python video processor.
Automatic publishing integration is implemented but requires
external service configuration and account authorization.
